## Статусы реестра

- **Проверить исправление**: есть код или свежий кейс ограниченного исправления; повторить исходный игровой сценарий.
- **Частично**: закрыт лишь подслучай/контентная часть.
- **Открыто**: сообщение владельца остаётся в очереди; причина в этом проходе не доказана.
- **Расширение**: желаемое продуктовое поведение; сначала зафиксировать правила.

Обозначения этапов: A — сеанс/переходы, B — прогресс/бой, C — транспорт/коллизии, D — туториал/диалог/UI, E — аудио, F — контент/материалы/мир, G — продуктовый ввод/настройки, P — производительность. Владельцы ниже — область диагностики, не утверждение о виновном компоненте. Нумерация сохраняет порядок списка владельца.
